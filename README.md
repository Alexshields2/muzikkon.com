# Muzikkon · Pulse demo

Frontend demo of Pulse running Muzikkon Musical Instruments (Dublin 22). Mock data only, no backend.

- `npm install`
- `npm run dev` to run locally
- `npm run build` for production (deploys as a static site; `vercel.json` handles routing)

All demo data lives in `src/data/muzikkon.ts` so numbers match across every screen.
